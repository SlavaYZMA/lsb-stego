# LSB-стеганография: прячем текст в картинку

Два простых Python-скрипта. Один прячет текст внутрь PNG-файла, второй читает его обратно и сохраняет в txt. Визуально картинка не меняется вообще.

---

## Как это работает

Каждый пиксель картинки хранит цвет в виде трёх чисел: красный, зелёный, синий (RGB). Каждое число от 0 до 255.

Мы берём **последний бит** числа красного канала и заменяем его на бит нашего текста.

```
Было:  красный = 11001101  (205)
Стало: красный = 11001100  (204)  ← изменили только последний бит
```

Разница между 205 и 204 невидима глазу. Но внутри спрятан наш текст.

Текст переводится в байты через **UTF-8** это позволяет прятать кириллицу, эмодзи и любые другие символы.

## Структура папки

```
encode.py              ← прячет текст в картинку
decode.py              ← читает спрятанный текст
first.png              ← исходная картинка (твоя)
message.txt            ← сюда вставляешь текст перед encode  ← СОЗДАЙ ВРУЧНУЮ
secret.png             ← результат (создаётся автоматически)
decoded_message.txt    ← расшифрованный текст (создаётся автоматически)
```

---

## Использование

### Шаг 1. Создай файл message.txt
Открой любой текстовый редактор, вставь текст, сохрани как `message.txt` в кодировке UTF-8 рядом со скриптами.

### Шаг 2. Зашить текст в картинку

**Windows (CMD):**
```cmd
python encode.py
```

**Mac / Linux (Terminal):**
```bash
python3 encode.py
```

Скрипт сам проверит что текст влезает. Если нет, то подскажет какое разрешение нужно.

### Шаг 3. Прочитать спрятанный текст

**Windows (CMD):**
```cmd
python decode.py
```

**Mac / Linux (Terminal):**
```bash
python3 decode.py
```

Результат сохранится в `decoded_message.txt` и выведется превью в консоль.

## Как изменить под себя

Открой `encode.py` — в самом верху три строки. Меняй только их:

```python
ВХОДНОЙ_ФАЙЛ  = r"C:\Users\1509sadik\Desktop\steno\first.png"
ВЫХОДНОЙ_ФАЙЛ = r"C:\Users\1509sadik\Desktop\steno\secret.png"
ФАЙЛ_ТЕКСТА   = r"C:\Users\1509sadik\Desktop\steno\message.txt"
```

В `decode.py` меняй две строки:

```python
ФАЙЛ         = r"C:\Users\1509sadik\Desktop\steno\secret.png"
ФАЙЛ_ВЫВОДА  = r"C:\Users\1509sadik\Desktop\steno\decoded_message.txt"
```

**Примеры для разных систем:**

На **Mac / Linux** пути без `r""` и с обычными слэшами:
```python
ВХОДНОЙ_ФАЙЛ  = "/Users/имя/Desktop/фото.png"
ВЫХОДНОЙ_ФАЙЛ = "/Users/имя/Desktop/secret.png"
ФАЙЛ_ТЕКСТА   = "/Users/имя/Desktop/message.txt"
```

Если файлы лежат **в той же папке что и скрипт** можно писать просто имя файла:
```python
ВХОДНОЙ_ФАЙЛ  = "фото.png"
ВЫХОДНОЙ_ФАЙЛ = "secret.png"
ФАЙЛ_ТЕКСТА   = "message.txt"
```

## Сколько текста влезает в картинку

Один русский символ = 2 байта = 16 пикселей.
Пробел = 1 байт = 8 пикселей.
В среднем ~15 пикселей на символ.

| Разрешение | Пикселей | Символов кириллицей |
|---|---|---|
| 1280×720 (HD) | 921 600 | ~61 000 |
| 1294×1696 | 2 194 624 | ~146 000 |
| 1920×1080 (Full HD) | 2 073 600 | ~138 000 |
| 2560×1440 (2K) | 3 686 400 | ~245 000 |
| 2723×3520 | 9 584 960 | ~639 000 |
| 3840×2160 (4K) | 8 294 400 | ~553 000 |

Если текст не влезает, то скрипт сам посчитает и напишет какое минимальное разрешение нужно.

## Частые ошибки и решения

**`ModuleNotFoundError: No module named 'PIL'`**
```
pip install Pillow
```

**`[ОШИБКА] Файл не найден`**
Проверь путь в переменной `ВХОДНОЙ_ФАЙЛ`. Самое простое это положить картинку в ту же папку что и скрипт и написать просто `"фото.png"`.

**`[ОШИБКА] Текст не влезает в картинку`**
Скрипт покажет точное минимальное разрешение и список подходящих стандартных разрешений. Используй картинку большего размера.

**`python` не найден на Mac / Linux**
Попробуй `python3` вместо `python`.

**Декодер говорит «текст не найден»**
Скорее всего читаешь из оригинальной картинки (`first.png`), а не из той в которую зашили текст (`secret.png`). Проверь путь в `decode.py`.

**Отправил через WhatsApp — текст потерялся**
WhatsApp пережимает фото при отправке и уничтожает скрытые биты. Отправляй файл как **документ**, не как фото. Или используй Telegram.

**Сохранил как JPEG — текст потерялся**
JPEG сжимает с потерями и уничтожает LSB. Используй только **PNG**.

---

## Ограничения

- Работает только с PNG (не JPEG, не WEBP)
- Не является криптографией. Текст спрятан, но не зашифрован. Тот кто знает про LSB-стеганографию сможет прочитать. Для защиты комбинируй с шифрованием
- При отправке через соцсети и мессенджеры отправляй файл как документ, иначе пережмут
