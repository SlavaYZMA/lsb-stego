# 🕵️ LSB-стеганография — прячем текст в картинку

Два простых Python-скрипта. Один прячет текст внутрь PNG-файла, второй — читает его обратно. Визуально картинка не меняется вообще.

---

## Как это работает (простыми словами)

Каждый пиксель картинки хранит цвет в виде трёх чисел: красный, зелёный, синий (RGB). Каждое число — от 0 до 255.

Мы берём **последний бит** числа красного канала и заменяем его на бит нашего текста.

```
Было:  красный = 11001101  (205)
Стало: красный = 11001100  (204)  ← изменили только последний бит
```

Разница между 205 и 204 — невидима глазу. Но внутри спрятан наш текст.

Текст переводится в байты через **UTF-8** — это позволяет прятать кириллицу, эмодзи и любые другие символы.

## Как изменить под себя

Открой файл `encode.py` — в самом верху три строки. Меняй только их:

```python
ВХОДНОЙ_ФАЙЛ  = r"C:\Users\1509sadik\Desktop\steno\first.png"
ВЫХОДНОЙ_ФАЙЛ = r"C:\Users\1509sadik\Desktop\steno\secret.png"
СООБЩЕНИЕ     = "сегодня в 22 у башни"
```

**Примеры:**

Спрятать другой текст:
```python
СООБЩЕНИЕ = "встречаемся в пятницу"
```

Использовать другую картинку:
```python
ВХОДНОЙ_ФАЙЛ = r"C:\Users\ИМЯ\Pictures\фото.png"
```

На Mac/Linux пути без `r""` и с обычными слэшами:
```python
ВХОДНОЙ_ФАЙЛ  = "/Users/имя/Desktop/фото.png"
ВЫХОДНОЙ_ФАЙЛ = "/Users/имя/Desktop/secret.png"
```

Открыть файл в текущей папке (без полного пути):
```python
ВХОДНОЙ_ФАЙЛ  = "фото.png"
ВЫХОДНОЙ_ФАЙЛ = "secret.png"
```

В `decode.py` меняй только одну строку:
```python
ФАЙЛ = "secret.png"   # путь к картинке со спрятанным текстом
```

## Частые ошибки и решения

**`ModuleNotFoundError: No module named 'PIL'`**
```
pip install Pillow
```

**`[ОШИБКА] Файл не найден`**
Проверь путь в переменной `ВХОДНОЙ_ФАЙЛ`. Частая причина — русские буквы или пробелы в пути. Проще всего положить картинку в ту же папку что и скрипт и написать просто `"фото.png"`.

**`python` не найден на Mac/Linux**
Попробуй `python3` вместо `python`.

**Картинка есть, но decode говорит «текст не найден»**
Скорее всего ты пытаешься читать из оригинальной картинки (`first.png`), а не из той в которую зашили текст (`secret.png`). Проверь путь в `decode.py`.

**Сохранил как JPEG — текст потерялся**
JPEG сжимает картинку с потерями и уничтожает спрятанные биты. **Используй только PNG.**

## Структура проекта

```
encode.py   — прячет текст в картинку
decode.py   — читает спрятанный текст
first.png   — исходная картинка (твоя)
secret.png  — результат с спрятанным текстом (создаётся автоматически)
```

---

## Ограничения

- Работает только с PNG (не JPEG, не WEBP)
- Ёмкость: 1 пиксель = 1 бит. Символ кириллицы = 16 бит = 16 пикселей. Фото 1000×1000 вмещает ~6000 символов кириллицы — более чем достаточно
- Не является криптографией — текст спрятан, но не зашифрован. Тот кто знает про LSB-стеганографию — сможет прочитать
